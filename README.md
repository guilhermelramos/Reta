# Reta

App de estudos para o vestibular. Lê o plano do dia, abre a aula do bloco e deixa perguntar ao professor sem parar o timer.

O plano fica neste aparelho. A chave da xAI, se você usar uma própria, também fica só no aparelho.

## Rodar

```bash
npm install
npm run dev
```

Abre em `http://127.0.0.1:8080`.
